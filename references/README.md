# Источники текущей конструкции

- [Pan–Tilt micromet / Thingiverse1941574](pan-tilt-1941574/README.md): исходный
  архив, лицензия, используемые STL/SCAD и изображения сборки.
- [MG996R](datasheets/mg996r/README.md): модель владельца и опубликованный паспорт.

Оригиналы хранить без изменений, рядом указывать происхождение, дату,
контрольную сумму и известные условия использования. Они не подменяют рабочие
FCStd в cad/. Лицензия Androsaur не распространяется автоматически на чужие материалы.

Исходники предыдущих концептов и невыбранных компонентов удалены из рабочего дерева;
они доступны в Git по метке before-modular-layout.
