# Первоначальные источники

Материалы, на которых основаны модели, хранятся здесь локально и версионируются
вместе с проектом. Для чтения чертежей не нужен доступ к внешнему сайту.
URL служит сведением о происхождении и способом найти обновления.

## Правила хранения

- `concepts/` — исходные эскизы и наброски владельца.
- `datasheets/<component-id>/` — оригинальные паспорта, размерные чертежи,
  изображения и другие материалы по покупному компоненту.
- Рядом с оригиналом хранить README: источник/URL, дату получения,
  исходное имя или идентификатор, описание, SHA-256, известного автора
  и условия использования. Неизвестные сведения отмечать явно.
- Файлы сохранять без преобразования, с реальным расширением формата.
  Не заменять оригинал обрезанной, увеличенной или размеченной картинкой.
  Производные изображения хранить отдельно, например в `derived/` рядом,
  и указывать, из какого оригинала они получены.
- Новую редакцию источника сохранять отдельным файлом с версией или датой;
  старый оригинал не перезаписывать. В документации компонента указывать,
  какая редакция использовалась для модели и как прочитаны спорные размеры.
- README компонента должен ссылаться прежде всего на локальный оригинал
  относительным путём. Не дублировать одну картинку в нескольких каталогах:
  один оригинал может обслуживать несколько моделей и экземпляров.
- При получении нового внешнего материала сохранять его в проект сразу,
  до использования как основы CAD. Если сохранить материал не удалось,
  явно фиксировать отсутствующий источник и зависимость от URL.

## Сохранность

Небольшие исходники, как текущие SVG и JPG, коммитить непосредственно в Git.
Для крупных материалов отдельно выбирать способ хранения; не добавлять
Git LFS автоматически. Архив должен оставаться доступным вместе с проектом.
Копия на GitHub защищает от исчезновения стороннего сайта, но для защиты
от потери самого репозитория нужна ещё независимая резервная копия:
зеркало Git или архив полного проекта на другом носителе. Автоматический
бэкап этим изменением не настраивается.
