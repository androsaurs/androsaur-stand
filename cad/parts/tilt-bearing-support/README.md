# Опора оси наклона

Статус: макет, не проверен изготовлением.

Условная посадка Ø16,3 под подшипник 6×16×5. Задняя часть опоры соединяется с шеей клеем в макете.

Опора — сплошная прямоугольная пластина 53×25 мм толщиной 11 мм,
без сужения к шее. Верх выровнен с шеей: Z=112 мм относительно диска.
Высота задаётся `Dimensions.PlateHeight`. Посадка и положение оси сохранены.

Размеры: таблица `Dimensions`; дерево построения редактируемое. STEP/STL обновляются при экспорте, а не автоматически.
