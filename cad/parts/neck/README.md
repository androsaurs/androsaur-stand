# Шея и крепление серво наклона

Статус: макет, не проверен изготовлением.

Высота оси над диском 100 мм. Две задние стойки и посадка заднего уха серво. Геометрия усилений предварительная.

Верх крепёжной площадки серво выровнен со стойкой: Z=112 мм от диска.
Прежний выступ на 2 мм убран; положение крепёжных отверстий сохранено.

Размеры: таблица `Dimensions`; дерево построения редактируемое. STEP/STL обновляются при экспорте, а не автоматически.
