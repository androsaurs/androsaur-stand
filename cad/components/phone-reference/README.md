# Телефон — габаритный макет

Статус: макет, не проверен изготовлением.

Размеры предположены по рисунку, не паспорт конкретной модели. Экран и камера — отдельные визуальные элементы сборки.

Размеры: таблица `Dimensions`; дерево построения редактируемое. STEP/STL обновляются при экспорте, а не автоматически.
