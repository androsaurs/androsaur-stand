# Androsaur Stand в SolidCraft

Это экспериментальный CAD-вариант, который хранится в репозитории параллельно с [build123d](../cadpy/).
Выбор варианта для дальнейшей работы ещё открыт. Пока рабочая модель, просмотрщик, печатные экспорты и базовые проверки запускаются из `cadpy/`.
Сборка SolidCraft сохраняется в отдельный файл `.sc`, который можно открыть и редактировать в приложении.

## Сборка

Нужны окружение build123d из [основного проекта](../docs/model-guide.md) и `solidcraft-cli` из SolidCraft 0.45.0. Из корня репозитория:

```bash
cadpy/.venv/bin/python solidcraft/build.py
```

Если `solidcraft-cli` установлен вне PATH, передайте `--cli /путь/к/solidcraft-cli`. По умолчанию результат лежит в `solidcraft/out/`. Для отдельной копии передайте `--out /путь/к/каталогу`. Сборка работает в отдельном процессе без GUI.

- `build.py` экспортирует свежую геометрию из build123d и собирает параметрическую механику SolidCraft. Установленные детали сохраняют положение из исходной сборки.
- `grip.json` хранит редактируемый профиль и параметры захвата. Он используется в сборке и отдельно воспроизводится командой `solidcraft-cli run solidcraft/grip.json --save grip.sc`.
- `out/androsaur-stand.sc` открывает сборку. `out/grip.sc` открывает деталь в ориентации для печати. `out/verification.json` описывает проверенные позы и пересечения.

Исходники эксперимента находятся в репозитории. Каталог `out/` игнорируется Git, и его можно пересобрать из исходников. Ручные изменения из GUI нужно сохранить отдельным файлом или перенести в командные исходники, чтобы они пережили пересборку.

## Управление и границы модели

- `Pan` вращает каретку и держатель вокруг Z. Значение совпадает с `pan_deg` в build123d. Пределы эксперимента 0…180°.
- `Tilt` вращает площадку и держатель вокруг оси Y каретки. Ноль в SolidCraft соответствует вертикальному телефону, то есть `tilt_deg=90` в build123d. Относительные пределы −92…+10° соответствуют углам −2…100° исходной CAD-модели. Эти пределы относятся к CAD.
- `phone_width` меняет внутреннюю ширину захвата. При 76,3 мм паз равен 77,3 мм, при 80 мм — 81 мм. Задняя перемычка захвата сохраняет форму. Спинка и габарит телефона пока импортированы, поэтому изменение `phone_thickness` в SolidCraft следует проверять вместе с ними.
- Если STEP-импорт SolidCraft пропускает `box_lower` из-за касательных граней, сборщик добавляет нижнюю половину как сетку из той же исходной детали. Сетка доступна в сборке для просмотра. Проверка твёрдых тел SolidCraft её не охватывает, поэтому для коллизий корпуса используйте штатные проверки build123d.

## Результат первого прогона

SolidCraft 0.45.0 собрал 32 тела вместе с сеткой нижней половины. Для пяти деталей сверены объёмы и габариты в четырёх позах. Для шести деталей механизма и держателя сверены попарные пересечения.

| Наклон build123d | Поворот | Пересечение в обоих CAD |
| ---: | ---: | --- |
| 90° | 0° | — |
| −2° | 0° | — |
| 45° | 45° | — |
| 100° | 180° | Кабель и основание, 30,91 мм³ |

При ширине телефона 80 мм захват перестроился до 6540,593 мм³ с сохранением посадочного профиля. Твердотельного пересечения со спинкой в контрольной позе нет. Это проверка CAD, фактическая посадка зависит от печати.

Геометрия механизма восходит к micromet / Thingiverse 1941574 (CC BY-SA). Профиль захвата восходит к STL владельца с неизвестной лицензией, как описано в [документации исходной модели](../docs/design.md).
