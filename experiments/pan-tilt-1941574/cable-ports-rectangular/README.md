# Вертикальные прямоугольные выходы

По просьбе владельца круглые выходы заменены вертикальными прямоугольными
со скруглением R2: зарядка12×18 мм (ширина×высота), моторы10×16 мм.
Центры остались на прежних уровнях1/4 и3/4 видимой высоты ножки.
Сторона+X, наружные габариты, полостьØ24 и все Placement не менялись.

Фактический штекер Type-C владельца пока не измерен; выбранные размеры
являются компоновочным допущением. Проверены размеры инструментов по Y/Z,
единое валидное тело и отсутствие добавления материала по сравнению
с вариантом с круглыми отверстиями.

Редактируемый исходник: ../hollow-base/base-hollow.FCStd.
RectangularPortDimensions задаёт ширину/высоту каждого выхода и R2;
геометрия — параметрические коробки и цилиндры, объединённые в инструменты
ChargingRectangle/MotorRectangle. Старые цилиндры сохранены скрытыми
и больше не участвуют в вычитании. Текущие STEP/STL обновлены в hollow-base/;
здесь дополнительные экспорты и макрос. Круглые экспорты cable-ports/ — история.
