# Круглая качалка под Base

Создана 2026-10-27 по фотографии владельца, для посадки в неизменённую Base.
Это номинальная компоновочная модель, не обмер комплектной качалки MG996R.
FCStd имеет редактируемые цилиндры, вычитания и таблицу Dimensions;
также сохранены STEP и STL.

Диск Ø21,1×3,8 мм лежит на дне выборки Base Ø21,4 глубиной4 мм:
низ на локальном Z8, верх Z11,8. Боковой зазор примерно0,15 мм.
Ступица Ø8,1 высотой4 мм направлена к мотору. Четыре отверстия Ø2,2
совпадают с крепежом Base: противоположные центры на расстоянии15,6 мм.
По последней просьбе владельца центральное сквозное отверстие расширено
до Ø6 мм под вал Øоколо5,6 мм из переданного STL. Первоначальное гнездо
Ø5,8 теперь полностью поглощено этим сквозным отверстием.
В текущей сборке качалка перевёрнута: ступица направлена внутрь Base,
диск остаётся в выборке Z8..11,8. Макрос строит исходную ориентацию;
последующие размещения задаются сборочным документом.

Диаметры под винты и размер ступицы — предположения для модели;
по фотографии точные размеры определить нельзя. Шлицы не моделировались,
передача момента и пригодность напечатанной качалки не подтверждены.
Для реальной сборки предпочтительна штатная качалка с её заводским шлицем,
её размеры нужно измерить и сверить с посадкой Base.

В сборку добавлен только App::Link BaseRoundHorn. Существующие детали
и их положения не менялись. build-horn.FCMacro защищает существующий файл
от перезаписи.
