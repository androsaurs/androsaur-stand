# Простой держатель телефона 170 × 80 мм

Создан по просьбе владельца после поворота верхнего узла на90°.
FCStd содержит редактируемые примитивы и таблицу Dimensions; также есть STEP/STL.
Толщина телефона условно10 мм. Внутренний зазор0,3 мм с каждой стороны,
спинка3 мм, боковые бортики и нижний упор2 мм. Верх открыт для установки.
Защёлки и передние удерживающие выступы не разработаны.
Четыре отверстия Ø3,4 совпадают с исходными отверстиями площадки.

В assembly-user-mg996r.FCStd добавлена группа PhoneMount с держателем
и полупрозрачным габаритом телефона. Её Placement связан выражением
с TiltPlatformReassembled.Placement: при повороте платформы новая группа
следует за ней автоматически. Не вращать её дополнительно при повороте
платформы, иначе получится двойной поворот. Существующие объекты не менялись.

При текущем вертикальном положении телефон имеет высоту170 мм, середина
на Z58,5 — высоте оси наклона (85 мм от краёв). Ось остаётся за телефоном,
а не внутри его толщины: расстояние центра телефона до оси20,5 мм.

Важное ограничение текущей компоновки: нижний край телефона Z−26,5,
подошва основания Z−6,291, то есть телефон ниже неё на20,209 мм.
Низ держателя ещё ниже: Z−28,8. Высота узла требует дальнейшего решения
владельца; существующую подставку при создании держателя не поднимали.

До этого изменения полная сборка зафиксирована коммитом3356088,
метка pan-tilt-assembled-v1. Держателя в той контрольной точке нет.
