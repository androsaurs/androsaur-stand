# Удлинённая ножка Base

По просьбе владельца цилиндр Base удлинён на33 мм, чтобы телефон170×80
с осью посередине высоты не выходил ниже подошвы. Верх цилиндра теперь
на45 мм от низа Base вместо12; выступ над подошвой толщиной4 мм —41 мм.

Изменён только Z вершин цилиндра и его выемки выше верхней плоскости
подошвы Z4. Подошва, X/Y всех вершин, диаметры и глубина посадки качалки
сохранены. Источники автора в references/ не менялись.

Весь механизм, обе качалки и скрытые детали платформы подняты на33 мм
вместе; Base осталась на месте. PhoneMount поднялась автоматически через
выражение связи с платформой. Взаимные положения сопряжённых деталей сохранены.
В текущей вертикальной позе запас под держателем10,491 мм.

base-raised.FCStd и base-raised.stl — новая ножка с подошвой в локальных
координатах; текущая сборка также сохранена. raise-base.FCMacro защищён
от повторного применения к уже удлинённой Base.
Старая сборка без телефона доступна по тегу pan-tilt-assembled-v1.
