# Полость для проводов в ножке Base

Последнее изменение: добавлены передние отверстия Ø12 под зарядный кабель
и Ø10 под провода моторов. Центры расположены на1/4 видимой высоты от
низа и верха соответственно. См. `../cable-ports/README.md`.

Актуализация после учёта Type-C: ножка дополнительно удлинена на25 мм.
В текущих FCStd/STEP/STL верх цилиндра Z70, верх полости Z63,
дно посадки качалки Z66. Диаметры и опорный слой3 мм не менялись.
Подробности — `../typec-clearance/README.md`.
Ниже сохранено описание этапа до этого дополнительного подъёма.

По просьбе владельца расширяется только внутренняя полость ножки,
без изменений остальных деталей и размещений сборки.

У существующей ножки наружный диаметр36,4 мм, верх наZ45 от подошвы.
Новая внутренняя полость Ø24 мм открывается снизу и заканчивается наZ38.
Номинальная стенка6,2 мм (около6,18 с учётом граней исходного STL).
Между полостью и дном посадки качалки Z41 остаётся опорный слой3 мм.
Посадка качалки, её крепёж, верхняя часть Z38..45, внешний цилиндр
и контур подошвы сохраняются. Центральная часть подошвы открыта для проводов.

Верхний выход проводов не добавлялся: сейчас сделана только полость,
как попросил владелец. Прочность, печать и окончательная трасса проводов
ещё не проверены; это не расчёт несущей способности.

base-hollow.FCStd — исходная геометрия, цилиндр CableCavity и вычитание;
диаметр и глубина полости редактируются в цилиндре. STEP/STL — экспорты.
Текущая mesh Base в сборке обновляется без изменения её Placement.
Исходник автора в references/ не редактируется.
