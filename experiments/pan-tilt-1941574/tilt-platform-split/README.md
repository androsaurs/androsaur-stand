# TiltPlatform — четыре части

По просьбе владельца разделена исходная конструкция micromet, Thingiverse
1941574: площадка; высокое и низкое крепления серво; опора оси.
Рёбра входят в соответствующие крепления. Граница по Z=1,5 в исходных
координатах — верхняя поверхность площадки. Новых крепежей не добавлено.

split.scad пересекает неизменённую авторскую SCAD-модель с четырьмя областями.
Исходный архивный STL содержит некорректные поверхности; импорт его в CGAL
завершается ошибкой. Поэтому части получены из авторского SCAD, без изменения
параметров конструкции. Это не гарантирует побитовое совпадение триангуляции.
Авторские рёбра/стыки также дают предупреждения non-manifold в трёх частях.
Они сохранены: исправлять конструкцию без указания владельца запрещено.
Файлы предназначены для раздельного просмотра/позиционирования, не являются
проверенным комплектом для печати. STL приложены как геометрические источники.

Для каждой части сохранён FCStd. В текущую сборку добавлена группа
TiltPlatformParts с четырьмя App::Link на тех же местах. Исходная TiltPlatform
сохранена скрытой; положение всех существующих объектов не менялось.
