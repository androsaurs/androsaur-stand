# Вставка в паз ServoSide

Сделана 2026-10-27 по просьбе владельца. Исходная ServoSide и размещения
семи деталей сборки не менялись. В сборку добавлен только App::Link ServoSideInsert.

Файлы: horn-insert.FCStd — редактируемая деталь; horn-insert.step — обмен;
horn-insert.stl — пробная печать. В Dimensions доступны толщина и диаметры.
Форма контура повторяет исходный OpenSCAD-паз с уменьшением на 0,15 мм
по периметру, толщина 2,8 мм при глубине паза 3 мм.
Три сквозных отверстия: центральное Ø3,2 мм, два Ø2,2 мм на расстояниях
11 и 17,5 мм от центра. Это номинальные допущения под M3 и M2, фактические
винты нужно сверить. Снизу выборка Ø6,8 глубиной 1,05 мм для конца вала.

Это геометрическая вставка, не проверенная шлицевая качалка:
шлицы не моделировались, передача момента и удержание винтом не проверялись.
Посадки требуют пробной печати на PLA. Внешний контур скопирован из
sideplateservo_std.scad, автор micromet, Thingiverse 1941574. В соответствии
с лицензией источника производная деталь распространяется на условиях
CC Attribution Share Alike; версия в поставленном LICENSE.txt не указана.
Не применять автоматически CC BY-NC-SA проекта к этой производной.

Макрос build-insert.FCMacro воспроизводит деталь и добавление ссылки,
отказывается перезаписывать существующий FCStd.
