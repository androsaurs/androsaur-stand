# Предварительное восстановление Pan–Tilt

`pan-tilt-review.FCStd` — отдельный сборочный эскиз по STL и фотографиям владельца.
`assembly-review.png` — обзор. Основная сборка `cad/assemblies/stand.FCStd` не менялась.

Шесть исходных сеток сохранены отдельными объектами без изменения формы.
Размещения восстановлены приблизительно: соосность, крепёжные отверстия,
контакты полки, нижняя опора и посадки качалок ещё не проверены.
Это визуальная реконструкция, не готовая к изготовлению проверенная сборка.
Верхняя платформа горизонтальна; механические сочленения не созданы.

Два App::Link указывают на существующую габаритную модель серво проекта.
Её артикул неизвестен: она не подтверждает совместимость с MG996R.
Владелец выбрал два MG996R 180°; реальные посадки предстоит сверить.
Потребуется всё дерево проекта для внешней ссылки на модель серво.

`build-review.FCMacro` воспроизводит эскиз через FreeCAD MCP в новом документе
и отказывается перезаписывать существующий FCStd. Исходник — в
`../../references/pan-tilt-stl/`. Автор и лицензия STL пока неизвестны.
