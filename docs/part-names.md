# Названия деталей и сборок

Этот словарь связывает русские названия в разговоре с постоянными
идентификаторами файлов и экземплярами модели. Читать при восстановлении
контекста работы над подставкой. Количества и пути к источникам — в [BOM](bom.csv).

## Текущая сборка Pan–Tilt с MG996R

Файл: `experiments/pan-tilt-1941574/assembly-user-mg996r.FCStd`.
Уточнение владельца от 2026-10-27:

| Название в разговоре | Что означает |
| --- | --- |
| Ножка, ножка подставки | Цилиндрический выступ детали `Base`, на который надет `PanCarrier` |
| Основание | Вся деталь `Base`, включая плоскую подошву и ножку |

Ножка в этой сборке является частью `Base`, а не отдельной деталью.
При обсуждении текущей сборки это значение имеет приоритет перед названием
старых опор `foot` ниже.

## Собственные детали

Файл каждой детали: `cad/parts/<идентификатор>/<идентификатор>.FCStd`.

| Название в разговоре | Допустимые уточнения и синонимы | Идентификатор |
| --- | --- | --- |
| Корпус основания | Тумба, корпус тумбы | `base-shell` |
| Дно | Дно основания, нижняя крышка | `base-bottom` |
| Крышка основания | Верхняя крышка тумбы | `base-cover` |
| Ножка | Опорная ножка | `foot` |
| Кронштейн нижнего серво | Кронштейн серво поворота | `pan-servo-mount` |
| Поворотный диск | Диск | `turntable` |
| Шея | Стойка за телефоном | `neck` |
| Опора подшипника наклона | Опора напротив вала серво | `tilt-bearing-support` |
| Люлька телефона | Люлька | `phone-cradle` |
| Скоба люльки | Задняя скоба, скоба наклона | `tilt-bracket` |
| Ось наклона | Ось опоры, отдельная ось напротив вала | `tilt-axle` |

«Вал серво» означает элемент сервопривода, а не отдельную деталь `tilt-axle`.
«Держатель телефона» может означать люльку или всю подсборку: если действие
затрагивает их по-разному, уточнить смысл до изменения модели.

## Покупные и условные компоненты

| Название в разговоре | Идентификатор источника |
| --- | --- |
| Серво, сервопривод | `servo-reference` — обязательно уточнять поворот или наклон |
| Телефон, макет телефона | `phone-reference` |
| Подшипник поворота, кольцевой подшипник | `pan-bearing-reference` |
| Подшипник наклона | `tilt-bearing-reference` |
| Качалка поворота | `pan-horn-reference` |
| Качалка наклона | `tilt-horn-reference` |
| Контроллер, макет платы управления | `controller-reference` |
| Модуль питания, макет питания | `power-reference` |
| Винт M3×10 | `m3-screw-reference` |
| Винт M3×8 | `m3-short-screw-reference` |

Источник компонента лежит в `cad/components/<идентификатор>/`.
Два серво используют один источник `servo-352944.FCStd`, но разные экземпляры.
Изменение источника повлияет на оба; изменение размещения экземпляра — только на него.

## Сборки

| Название в разговоре | Файл в `cad/assemblies/` |
| --- | --- |
| Полная сборка, вся подставка | `stand.FCStd` |
| Основание в сборе | `base.FCStd` |
| Поворотный узел, вся поворотная часть | `turntable.FCStd` |
| Узел наклона, голова в сборе | `tilt-head.FCStd` |
| Держатель в сборе, люлька с телефоном и скобой | `phone-holder.FCStd` |

Отдельный диск `cad/parts/turntable/turntable.FCStd` и сборка
`cad/assemblies/turntable.FCStd` — разные документы. В разговоре различать
«поворотный диск» и «поворотный узел».

## Повторяющиеся экземпляры и стороны

Стороны считаем в нулевом положении со стороны человека, смотрящего
на экран телефона: справа +X, слева −X, спереди −Y, сзади +Y.
Эти обозначения сохраняются при повороте модели и смене вида камеры FreeCAD.

| Экземпляр в разговоре | Документ | Имя объекта FreeCAD |
| --- | --- | --- |
| Серво поворота, нижний серво | `base.FCStd` | `PanServo` |
| Серво наклона, верхний серво | `tilt-head.FCStd` | `TiltServo` |
| Передняя левая ножка | `base.FCStd` | `Foot4` |
| Передняя правая ножка | `base.FCStd` | `Foot3` |
| Задняя левая ножка | `base.FCStd` | `Foot2` |
| Задняя правая ножка | `base.FCStd` | `Foot1` |

Для винтов указывать узел и место, а при необходимости имя объекта
из дерева FreeCAD. Если экземпляр не определяется однозначно, уточнить его.

## Как адресовать изменения

Примеры: «У люльки увеличь толщину спинки», «У `phone-cradle` расширь
окно зарядки», «Смести серво наклона назад», «Измени переднюю левую ножку».
Для точной ссылки подходят идентификатор детали, путь к FCStd или имя
объекта вместе с документом. Скриншот с выделением помогает указать
конкретную грань или элемент.

Новые названия и переименования фиксировать здесь, согласовывая изменения
с BOM и ссылками. Старые разговорные названия сохранять как синонимы,
если они не создают неоднозначности.
