# Координаты и интерфейсы макета

Единицы — миллиметры. Общий ноль — центр основания на столе.
X направлен вправо для человека перед телефоном, Y назад, Z вверх.
Нулевые углы: телефон вертикален, экран смотрит вдоль −Y.

| Интерфейс | Положение и размеры |
| --- | --- |
| Поворот | Ось Z через X=0, Y=0; начало подвижной группы Z=83 |
| Наклон | Ось X через Y=5, Z=187 |
| Подшипник поворота | Ø90/56, высота 5, Z=78…83 |
| Опора наклона | Подшипник 6×16×5; X=−32…−27, Y=5, Z=187 |
| Ось наклона | Ø6×18; X=−40…−22 |
| Корпус / крышки | 4 винтовых оси X=±60, Y=±28 |
| Шея / диск | X=−29 и 5, Y=39 и 43; отверстия Ø3,4 |
| Люлька / скоба | X=±18, Z=±8 относительно оси наклона; отверстия вдоль Y |
| Серво наклона / шея | Винты вдоль X; Y=39,2, Z=187±4,95 |
| Общий верх стоек, площадки серво и опоры | Z=199 в сборке, Z=112 над диском; без ступенек |
| Пластина опоры наклона | 53×25×11; локальный диапазон Z=−13…12 относительно оси |

Подсборка `tilt-head.FCStd` имеет локальное начало на верхней плоскости
диска: наклон находится на локальном Z=100. `phone-holder.FCStd` имеет
ось в локальных Y=5, Z=0; группа `Tilt` компенсирует смещение Y перед вращением.
Собственные компоненты сохраняют локальные координаты и получают размещение
через `App::Link` с `LinkTransform=True`.

Положительные углы следуют правилу правой руки: `Pan.Yaw` вокруг +Z,
`Tilt.Pitch` вокруг +X. При положительном Pitch верх телефона отклоняется
вперёд, к человеку. Это углы CAD-макета, не калибровка реальных серво.
Параметры пока не имеют программного ограничения диапазона.

Для сквозных отверстий M3 приняты Ø3,4, для условных пилотных отверстий
Ø2,6. Посадка внешнего кольца подшипника наклона Ø16,3. Эти допуски
предварительные, без проверки материала и принтера. На оси и в качалках
не разработаны стопоры и реальные посадки.

Ссылки деталей и подсборок образуют направленное дерево зависимостей:
детали → подсборки → общая сборка. Детали не зависят от общей сборки.
`layout.FCStd` — самостоятельная компоновочная модель; её таблица пока
не управляет размерами всех файлов. Изменения сопряжённых размеров
согласовывать вручную по этой таблице интерфейсов.
