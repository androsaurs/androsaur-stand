# Интерфейсы подсборок

Единицы — мм. Корень pan-tilt.FCStd: `Module`. Его начало — центр основания
на плоскости подошвы. Оси сохраняют ориентацию принятой модели: Z вверх,
фасад к телефону — +X, ось наклона — вдоль Y.

| Интерфейс | Где | Значение |
| --- | --- | --- |
| BaseInterface / BaseMount | Module механизма | Начало в центре подошвы, Placement единичный |
| PhoneInterface / PhoneMount | Module механизма | Полная система координат площадки, следует за Pan и Tilt |
| MountInterface / Mount | Module держателя | Входной интерфейс, Placement единичный |

В общей сборке источник PanTilt — `Module` из pan-tilt.FCStd; источник PhoneHolder —
`Module` из phone-holder.FCStd. Корневой Placement PanTilt сохраняет принятое
мировое положение модели. Связь держателя: `PanTilt.Placement * PanTilt.PhoneInterface`.
Это связь координат, не расчёт сил и не решатель механических контактов.

В механизме группа Fixed неподвижна. Pan содержит корпус нижнего серво,
PanCarrier, обе боковины и качалку наклона. Tilt вложена в Pan и содержит
корпус верхнего серво и площадку. Начало Pan лежит на вертикальной оси,
начало Tilt — на оси опорного выступа. Текущая вертикальная поза принята
за исходное положение групп. Наклон менять вокруг локальной Y, поворот — Z.

В координатах PhoneInterface локальная X направлена вдоль высоты телефона,
Y — вдоль его ширины и оси наклона. Телефон находится со стороны отрицательной Z
площадки. Его середина по высоте совпадает с осью; ось расположена за телефоном,
а не внутри его толщины. Задняя плоскость держателя прилегает к площадке Z=−1,5.

Не привязывать новый корпус к случайным граням или номерам рёбер. Предпочитать
именованный интерфейс и собственный монтажный Placement. Положение интерфейса
менять в модуле-владельце; геометрию детали — только в её исходнике.
