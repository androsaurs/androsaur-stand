# Запуск и проверка вьювера

Рабочая модель — Python/build123d в `cadpy/`. Просмотр через OCP CAD Viewer;
FreeCAD для запуска не нужен. Хаб `androsaur-hub` тоже не требуется.

## Запуск

Из корня репозитория:

```bash
./cadpy/viewer.sh
```

Открыть **http://127.0.0.1:3939/viewer**. Можно открыть вкладку после запуска,
обновить страницу или открыть ещё одну вкладку: последняя модель хранится
в памяти сервера и автоматически отправляется после готовности страницы.
Первое построение занимает некоторое время; до его окончания виден логотип OCP.
Терминал с процессом нужно оставить работающим. Остановка — Ctrl+C.

Для другого порта: `./cadpy/viewer.sh 3940` (такой же порт указать в URL и проверках).
При занятом порте сначала выяснить, какой процесс его использует; не завершать
чужие процессы. Повторный запуск на занятом порте должен закончиться ошибкой.

При первой установке:

```bash
cd cadpy
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./viewer.sh
```

`viewer.sh` ждёт готовности сервера, затем запускает `ocp123d`, который строит
модель и следит за изменениями. `TILT` и `PAN` заданы в `view.py`.
При необходимости вручную переслать модель:

```bash
cd cadpy
.venv/bin/python view.py
```

## Что считать успешным запуском

HTTP 200, открытая страница, регистрация WebSocket и завершение `view.py` с кодом 0
по отдельности не подтверждают отображение сборки. Нужно получить подтверждение
от браузера, что он построил дерево с группами `stand`, `holder`, `enclosure`,
`electronics` и `fasteners`:

```bash
cd cadpy
.venv/bin/python viewer_status.py
```

Успех: `ready: true`, `browser_count` больше нуля и все подключённые вкладки
подтвердили текущую модель (`confirmed_browsers == browser_count`). Скрипт
завершается с ненулевым кодом, если сборка ещё не подтверждена.
В журнале сервера появляется `Browser confirmed assembly generation N`.

Перед сообщением владельцу «вьювер запущен, модель отображается» сохранить
и **просмотреть** скриншот самого вьювера:

```bash
.venv/bin/python viewer_status.py --screenshot /tmp/androsaur-stand-viewer.png
```

Агент просматривает полученный PNG через инструмент просмотра изображений.
На нём должна быть сборка подставки. Сохранение скриншота без его просмотра
не является визуальной проверкой. При нескольких вкладках снимок относится
к последней активной на сервере; состояние дерева проверяется для всех.

## Если виден только логотип

Посмотреть `curl -fsS http://127.0.0.1:3939/health` и журнал запуска:

- `model_cached: false` — модель ещё строится либо `view.py` завершился ошибкой.
  Дождаться построения или устранить ошибку из журнала.
- `browser_count: 0` — страница не прислала дерево; проверить URL, соединение
  WebSocket и ошибки JavaScript/WebGL в консоли браузера.
- Модель сохранена, браузер подключён, но `ready: false` — он ещё не подтвердил
  отрисовку текущей сборки. Проверить журнал и консоль браузера.
- `/health` возвращает 404 — запущен прежний сервер напрямую через
  `python -m ocp_viewer`. Использовать проектный `viewer.sh`.

Причина инцидента 09.11.2026: прежний сервер отправлял модель только текущему
клиенту и не сохранял её для позднего открытия/обновления вкладки. Агент
ошибочно считал код возврата скрипта доказательством загрузки. Теперь
`viewer_server.py` сохраняет модель и передаёт её каждой готовой вкладке;
`viewer_status.py` проверяет подтверждение дерева от браузеров.

Регрессионная проверка доставки без построения CAD: из `cadpy/`
`.venv/bin/python -m unittest test_viewer_server -v`.
