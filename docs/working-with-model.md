# Работа с моделью

Открыть cad/assemblies/stand.FCStd со всем деревом cad/. Подсборки и детали
можно открывать отдельными вкладками. FreeCAD подгружает ссылки автоматически.

Чтобы изменить ножку, открыть parts/base/base.FCStd. Здесь сохранены исходная
форма, полость CableCavity, размеры прямоугольных выходов RectangularPortDimensions
и вычитание Base. Чтобы изменить телефонный держатель, открыть
parts/phone-holder/phone-holder.FCStd: размеры находятся в Dimensions.
У нескольких исходных деталей и MG996R геометрия пока сеточная, а не дерево эскизов.

Сохранять изменённую деталь, пересчитать и сохранить зависимые подсборки,
затем stand.FCStd. Общая сборка не должна содержать новых копий геометрии.
Не перемещать деталь в её исходнике ради компоновки — менять Placement её ссылки
в соответствующей подсборке. Не менять координаты соседних элементов автоматически.

Для компоновки целого механизма менять PanTilt в stand.FCStd. Держатель связан
с PhoneInterface и следует за ним. Для наклона менять группу Tilt в pan-tilt.FCStd,
сохраняя её Base и вращая вокруг локальной Y. Для поворота — группу Pan вокруг Z.
Вставка ServoSideInsert остаётся в Pan, корпус верхнего серво — в Tilt.
Основание и круглая качалка остаются в Fixed.

Новый модуль (например, корпус электроники) создать отдельным документом
с корневым App::Part Module и входным MountInterface. Добавить его через App::Link
в stand.FCStd и совместить вход с BaseInterface или иным объявленным интерфейсом.
Так корпус можно проектировать на своей вкладке, сохраняя возможность общей сборки.

Для проверки запустить scripts/verify-model.FCMacro через FreeCAD MCP.
Он читает документы и проверяет ссылки и выражения, FCStd не сохраняет.
Проверка структуры не заменяет проверки зазоров, печати и реального крепежа.

Экспорты — exports/parts/<деталь>/, общий вид — exports/assemblies/stand.png.
После изменения FCStd актуализировать нужный экспорт; старый STL не обновляется сам.
Для обновления экспортов всех деталей и общего вида использовать
scripts/export-model.FCMacro через MCP FreeCAD.

Контрольные точки: pan-tilt-assembled-v1 (3356088), телефон и круглая кабельная
перфорация (173e2ee), полное состояние перед очисткой before-modular-layout (9d254f3).
Для просмотра старой версии использовать отдельный git worktree; не делать
сброс текущей рабочей директории с незакоммиченными правками.
