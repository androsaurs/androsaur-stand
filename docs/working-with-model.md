# Работа с макетом

Названия для обсуждения изменений и точные идентификаторы приведены
в [словаре деталей и сборок](part-names.md).

## Открыть сборку

Откройте `cad/assemblies/stand.FCStd` в FreeCAD. Сохраните весь репозиторий
вместе: FCStd деталей нужны для внешних ссылок. Главный файл ссылается
на `base.FCStd` и `turntable.FCStd`; поворотный узел ссылается на
`tilt-head.FCStd`, а тот — на `phone-holder.FCStd`.

Внешние документы подгружаются FreeCAD при открытии. Если нужного документа
нет во вкладках, откройте соответствующий FCStd явно. Общая сборка
остаётся доступной для наблюдения результата.

## Поворот и наклон

В документе `stand.FCStd` выберите группу `Pan` и поменяйте `Yaw` во вкладке
свойств «Данные» / `Motion`. В документе `tilt-head.FCStd` выберите группу `Tilt`
и поменяйте `Pitch`. Для начала используйте Yaw от −90° до +90°,
Pitch от −30° до +30°. Пересчитайте затронутые документы, если вид не обновился.

Из консоли Python FreeCAD:

```python
stand = next(d for d in App.listDocuments().values()
             if d.FileName.endswith('/assemblies/stand.FCStd'))
head = next(d for d in App.listDocuments().values()
            if d.FileName.endswith('/assemblies/tilt-head.FCStd'))
stand.getObject('Pan').Yaw = 25
head.getObject('Tilt').Pitch = 20
for _ in range(3):
    for doc in App.listDocuments().values():
        doc.recompute()
```

Сохранение угла наклона меняет файл подсборки `tilt-head.FCStd`;
сохранение угла поворота меняет `stand.FCStd`.
Это параметрическая демонстрация двух осей, а не сборка с решателем
механических сочленений. Геометрия расположена явно; силы и контакты
не моделируются.

## Редактировать детали

Откройте нужный файл из `cad/parts/<id>/` или `cad/components/<id>/`.
Основные размеры находятся в таблице `Dimensions`. Детали построены
редактируемыми примитивами, объединениями и вычитаниями; размеры
части элементов заданы непосредственно в свойствах примитивов.
Меняйте таблицу или исходный элемент, затем пересчитывайте и сохраняйте
документ. Сборки используют ссылки на него, а не копии геометрии.

Посадочные координаты и некоторые размеры пока заданы численно.
Изменение габарита не гарантирует автоматического переноса всех отверстий
или компонентов. После изменений проверяйте интерфейсы и общую сборку.

Для просмотра внутренностей в `base.FCStd` скройте ссылки `base_shell`
и `base_cover` пробелом. Для возврата включите их видимость.
Подсборки можно открывать и рассматривать независимо.

## Экспорты и обзорные виды

В каждой папке собственной детали есть FCStd, STEP, STL, README
и SVG с тремя проекциями. SVG — обзор без полного комплекта размеров;
это не утверждённый производственный чертёж. Для металлооси STL служит
только геометрическим представлением, не указанием печатать её.

В `cad/assemblies/exports/` есть STEP общей сборки, виды спереди,
сбоку, изометрия, пример положения и вид с открытым основанием.
Экспорты являются снимками и не обновляются при сохранении FCStd.
После редактирования экспортируйте изменённые детали и сборку заново.

## Макросы

- `scripts/build_mockup.FCMacro` воспроизводит исходный макет целиком.
  Он по умолчанию защищает уже существующие файлы от перезаписи.
  После ручного редактирования используйте его в отдельной копии репозитория.
- `scripts/check_mockup.FCMacro` проверяет текущие открытые документы
  или подгружает сборку с диска. Сохраняет JSON-отчёт и два превью;
  возвращает прежние углы и видимость. FCStd не сохраняет.
- `cad/components/servo-reference/build_servo.FCMacro` воспроизводит
  только исходную модель сервопривода, а не всю подставку.

Проверка STEP относится к существующему экспорту. После изменения FCStd
сначала обновите STEP. Результаты исходного построения находятся
в `docs/build-report.json`, проверки — в `docs/verification-report.json`.
