# Организация моделей

Актуальная структура после очистки 2026-10-27. В рабочем дереве одна конструкция.

```text
cad/
├── components/                 # покупные изделия и габариты
│   ├── mg996r/mg996r.FCStd      # один источник, два экземпляра
│   └── phone/phone.FCStd
├── parts/                      # изготовляемые детали
│   ├── base/base.FCStd
│   ├── pan-carrier/pan-carrier.FCStd
│   ├── servo-side/servo-side.FCStd
│   ├── shaft-side/shaft-side.FCStd
│   ├── tilt-platform/tilt-platform.FCStd
│   ├── tilt-horn/tilt-horn.FCStd
│   ├── pan-horn/pan-horn.FCStd
│   └── phone-holder/phone-holder.FCStd
└── assemblies/
    ├── pan-tilt.FCStd           # механизм
    ├── phone-holder.FCStd       # держатель и телефон
    └── stand.FCStd              # общая компоновка
exports/                        # снимки для обмена и изготовления
references/                     # оригиналы сторонних материалов
docs/                           # текущая документация
scripts/                        # проверка
```

Деталь — один документ. Геометрию редактировать в нём. Покупное изделие
использовать через повторные App::Link; оба MG996R ссылаются на один объект.
Верхняя площадка — одна деталь; внутри её документа сохранены четыре
геометрических элемента, уже в принятых относительных положениях.

Подсборка — отдельный документ с корневым App::Part `Module`. Он содержит
ссылки на детали и именованные опорные системы координат. Подсборку можно
открывать, изучать и изменять независимо. Внешние модули не зависят от неё
геометрией: связь идёт через опорный интерфейс.

Общая stand.FCStd содержит только экземпляры модулей. PhoneHolder.Placement
вычисляется через `PanTilt.Placement * PanTilt.PhoneInterface`. Поэтому держатель
следует за механизмом, а перенос всей подставки не требует двигать каждую деталь.

Корпус электроники пока не спроектирован. Для него создать отдельные детали
в parts/ и сборку electronics-case.FCStd с корневым Module и MountInterface.
Затем добавить ссылку в stand.FCStd и совместить интерфейс корпуса с
BaseInterface механизма. До этого пустые заготовки и условные объёмы не добавлять.

Старые варианты и промежуточные экспорты удалены. История — Git,
`before-modular-layout`, а не каталоги old/final/v2. Экспорты не являются источником
геометрии и обновляются после изменения FCStd. Проверенный печатный комплект
пока не выпускался.
