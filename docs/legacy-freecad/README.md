# Архив: модель во FreeCAD

Это документация прежней модели, собранной во FreeCAD (`cad/`, `scripts/*.FCMacro`, `exports/`).
Владелец отказался от FreeCAD в пользу build123d (2026-11-04). Актуальная модель — `cadpy/`,
актуальные документы лежат на уровень выше (`docs/`).

Файлы `cad/*.FCStd` и макросы сохранены как архив и источник сравнения, но не развиваются.
Ссылки внутри этих документов указывают на старую структуру и могут устареть.
